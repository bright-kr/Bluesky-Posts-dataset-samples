# Bluesky Posts Dataset Sample

<h2>1,892개 레코드의 샘플 dataset</h2>

<a href="https://brightdata.co.kr">
    <img src="https://github.com/bright-kr/Bluesky-Posts-dataset-samples/blob/main/datasets-image.png" alt="Bright Data datasets" />

이 **Bluesky Posts Dataset Sample**에는 **1,892개 레코드**가 포함되어 있으며, **Bright Data API**를 사용해 추출되었습니다.

## 데이터 포인트

| 필드 이름 | 설명 |
|------------|-------------|
| `url` | Bluesky 플랫폼의 특정 게시물로 바로 연결되는 URL입니다. |
| `post_id` | 각 게시물의 고유 식별자입니다. |
| `post_date` | 게시물이 게시된 날짜와 시간입니다. |
| `posted_by` | handle 및 프로필 링크를 포함한, 게시물을 작성한 사용자 정보입니다. |
| `post_text` | 게시물의 텍스트 콘텐츠입니다. |
| `comments` | 게시물에 작성된 댓글 수입니다. |
| `reposts` | 다른 사용자가 해당 게시물을 repost한 횟수입니다. |
| `likes` | 게시물이 받은 총 좋아요 수입니다. |
| `reposted` | 해당 게시물이 다른 사용자의 콘텐츠를 repost한 것인지 여부를 나타냅니다. |
| `external_links` | 게시물에 포함된 외부 웹사이트 링크입니다. |
| `images` | 게시물에 첨부된 이미지 수입니다. |
| `videos` | 게시물에 첨부된 동영상 수입니다. |
| `original_post` | 콘텐츠가 원본인지 repost된 것인지 여부를 나타냅니다. |
| `pinned` | 게시물이 사용자의 프로필 상단에 고정되어 있는지 여부를 나타냅니다. |
| `discovery_input` | 콘텐츠 탐색에 사용되는 키워드 또는 태그입니다. |
| `contains_video` | 게시물에 동영상이 포함되어 있는지 여부를 나타냅니다. |
| `profile_followers_count` | 게시물 작성자가 보유한 팔로워 수입니다. |
| `profile_follows_count` | 게시물 작성자가 팔로우하는 사용자 수입니다. |
| `profile_posts_count` | 사용자가 작성한 총 게시물 수입니다. |
| `post_type` | 텍스트, 이미지, 동영상 등 게시물의 유형입니다. |
| `video_thumbnails` | 게시물에 포함된 동영상의 썸네일 이미지입니다. |
| `video_duration` | 게시물에 포함된 동영상 길이(초)입니다. |


## 활용 사례

### 1. 소셜 미디어 감성 분석
게시물의 텍스트 콘텐츠와 참여 지표를 분석하여 다양한 이슈에 대한 대중의 감성을 분석합니다.

### 2. 인플루언서 영향력 평가
팔로워 수와 참여 비율을 분석하여 주요 인플루언서를 식별하고 다양한 사용자의 영향력을 평가합니다.

### 3. 콘텐츠 성과 벤치마킹
여러 프로필의 게시물 성과를 비교하여 모범 사례를 도출하고 콘텐츠 전략을 최적화합니다.
